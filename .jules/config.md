# Projet

Application web moderne.

# Stack

- React
- TypeScript
- TailwindCSS
- Supabase

# Objectif

Maintenir une application stable, moderne et responsive.

# Règles importantes

- Ne jamais casser le responsive mobile
- Respecter TypeScript strict
- Ne jamais supprimer les traductions FR/EN
- Faire les plus petits correctifs possibles
- Préserver les composants existants
- Ne jamais exposer de secrets ou clés API

# Style de code

- Code propre et lisible
- Éviter la duplication
- Respecter l’architecture existante
